# Holberton School - Web Front-End

This repository contains front-end web development projects completed as part of the Holberton School curriculum. The projects focus on building accessible, semantic, and visually consistent web pages using HTML and CSS.

## Projects

| Directory                         | Description                                                                                                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`html_advanced`](html_advanced/) | Builds the semantic HTML structure of the Techium website using headings, sections, navigation, lists, tables, media, links, and accessibility practices.                                |
| [`CSS_advanced`](CSS_advanced/)   | Applies advanced CSS styling to the Techium website, including custom properties, typography, selectors, layout systems, navigation, cards, dark themes, transitions, and visual assets. |

## Learning Objectives

Through these projects, I learned how to:

* Structure web pages with semantic HTML5 elements
* Follow accessibility and web standards
* Organize content using reusable sections and components
* Use CSS selectors, specificity, inheritance, and custom properties
* Build layouts with floats, grids, and reusable column classes
* Style navigation menus, cards, buttons, forms, and footers
* Work with images, SVG icons, fonts, and favicons
* Implement light and dark section themes
* Add transitions and interactive visual states
* Maintain a consistent design system across multiple pages

## Technologies
