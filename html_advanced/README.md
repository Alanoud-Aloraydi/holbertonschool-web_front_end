# Advanced HTML - Techium

## Description
This project focuses on building a modern HTML5 webpage skeleton for a digital agency named Techium. The pages implement standard W3C-compliant semantic HTML tags (`<header>`, `<main>`, `<footer>`, `<section>`, `<article>`, `<aside>`, `<nav>`) and strictly follow proper hierarchical structuring without any CSS styling.

## Learning Objectives
* Understand guidelines and semantic rules for modern HTML5.
* Create a complete HTML5 web page skeleton including viewport, favicons, meta tags, and charset.
* Appropriately use level 1 to level 6 headings following strict document outline hierarchy.
* Differentiate between semantic structural elements (`div`, `span`, `header`, `main`, `footer`, etc.).
